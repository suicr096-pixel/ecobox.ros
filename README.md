# Ecobox — versión visual para VS Code

Esta versión es un prototipo completo en un solo `index.html`, con CSS y JavaScript incluidos.

## Incluye
- Diseño visual moderno inspirado en apps de delivery.
- Identidad visual Ecobox.
- Hero, navegación y sección de impacto.
- Ofertas con tarjetas, descuentos, filtros y buscador.
- Detalle de producto.
- Carrito lateral.
- Reserva y código de retiro.
- Historial de reservas.
- Panel para comercios.
- Publicación de ofertas.
- Responsive para celular.
- Animaciones, sombras, estados y botones.
- `localStorage` para conservar datos.
- Las 3 imágenes originales del documento están en `assets/`.

## Abrir
Abrí `index.html` en VS Code y luego en el navegador. No necesita instalar dependencias.
